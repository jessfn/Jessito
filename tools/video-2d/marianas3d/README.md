# Fosa de las Marianas (3D + 2D)
Personaje 3D (Ready Player Me `youth.glb`) sobre mundo 2D. Los modelos y animaciones NO se guardan en el repositorio:
- `models/youth.glb`: PreviewMesh.glb de `rpm-unity-sdk-core` (jsDelivr).
- `anim/*.fbx`: `M_Standing_Idle_001`, `M_Falling_Idle_002`, `M_Standing_Idle_Variations_002/005`, `M_Standing_Expressions_010` desde `media.githubusercontent.com/media/readyplayerme/animation-library/master/masculine/fbx/<carpeta>/<nombre>.fbx`.
- `node_modules/three` (three.js).
Uso: `node still.js <t...>` para fotogramas; `run.sh` renderiza 16 tramos (3 en paralelo, 4K, 60 fps).
